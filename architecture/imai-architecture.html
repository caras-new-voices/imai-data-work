3. The event pipeline (how behavior becomes data)

  • Three emitters, one contract: fire-and-forget axios POST to CLOSE_WEBHOOK_URL ("PipeDrive" in code is a legacy misnomer — it's the Close webhook). No retry, no queue, no dead-letter anywhere — every downstream gap (Mixpanel loss, Klaviyo ~10%, April-2026 thin patch) is consistent with best-effort delivery.
  • White-label: per-label URLs (CLOSE_WEBHOOK_URL_<LABEL>) but tenant identity is stripped from payloads → reseller traffic is indistinguishable downstream (Q13).
  • ~55 named events + dynamic families — full dictionary with caveats per event: docs-events-audit/02-event-dictionary.md; Mixpanel-side meanings: 12-mixpanel-lexicon.md.
  • Parallel side channels: GA4 MP server purchase (Q11), make.com cancellation hook, Slack alerts ×5 families, Bubble ip-capture/blocked-signup, proxy billing tables (a second usage truth unaffected by webhook loss), ai_usage cost table.

6. Money (for any feature touching revenue)

  • Two engines: self-serve (Stripe + Cardcom-IL; observed price points 99/175/499/599/959/1199-1200 + custom — docs only list 99/499/1200) and sales-led (manual Close deals = majority of paying accounts).
  • Revenue truth: prod user_payments (self-serve) + Close (manual). Webhook events saw ~36% of recurring dollars — never sum them.
  • Latest measured state (2026-07, Stripe engine only, Q28): gross fell ~$150.8k→$67.3k/mo Nov→Jun while trial→paid recovered to 20% and payers grew — a plan-mix decline, not a demand problem. Full report: docs-events-audit/13-sales-funnel-report-2026-07.md.

7. Standing rules & sharp edges (read before building)

  • Never push to Discovery-imai from data-work sessions — all docs/analysis go to caras-new-voices/imai-data-work.
  • Exclude user_created_by_admin accounts from funnels; roll team members up via main_user_id; calendar-day windows.
  • Event birth dates: cancel_trial 2026-04-22 · trial_* friction 2026-06-30 · created_list 2026-07 — trends crossing them are measurement changes.
  • created_campaign AND campaign_created both fire (Q9); payment_failed is dunning noise (count distinct users); trial_analytics_report.cancel_date counts any %cancel% event.
  • Amounts are whole USD; IL ×1.17 VAT on some paths; Close deal values are cents.
  • proxy prod convention is production, backend/main's is prod — check before adding env gates.
  • Raw email flows into GTM dataLayer / Clarity / Segment; ~50 white-label domains load IMAI tags; no CMP found in code (Q12/Q15).
  • Abuse gate blocks ~31% of card-enterers (US 22%, UK 31%, PH 49%, Apr–Jul 2026) — block reasons only in the logs DB (Q27).
