Feature map

Every product module: what it does, where it lives, what it emits, how it's metered. Code refs @ da98fcf2.

Core product

Influencer Discovery Search

Cross-platform influencer search (Instagram/TikTok/YouTube + LinkedIn, Snapchat variants). The highest-volume feature by far.
  • Code: proxy (fronting the search API) + Influencer.controller.ts
  • Events: influencer_discovery_search (~2.8M rows), _paginated; import twin "Influencer Search" (41% lower, Q25)
  • Metering: proxy billing tables, package type 1; trial quota with the Jul-21 search-session window (searches within ~50s of the last counted one are free — code default 50s, comment claims 300s)
  • Health-score input

Influencer Reports

Deep per-influencer analysis (audience, performance). The activation feature.
  • Code: reports/report.controller.ts
  • Events: report_creation_attempt/created_report/report_creation_failed, first_report_created = the activation milestone; import twin "Influencer Report" (props: Report ID, Influencer ID, Platform)
  • Metering: package type 2; trial daily/total report limits → friction events

Campaigns

Campaign workspace: add influencers, requirements/approvals, invites, chat, post tracking.
  • Code: campaigns.controller.ts + campaigns-api (bulk) + Cloud Run campaign-tracker (post-metrics scraping) + Phyllo creator-auth status (via pixel-DB phyllo_webhooks, new Jul-21)
  • Events: created_campaign+campaign_created (both fire, Q9), first_campaign_created, influencer_added_to_campaign; import family "Created Campaign", "Campaign Media Scraped" (~6.6k/30d), "Campaign Invite", "Campaign Chat Message", "Campaign Requirement Approval", "Added Tracked Campaign Influencer"

Lists

Save/organize influencers into lists.
  • Code: lists/list.controller.ts
  • Events: first_list_created only (the every-time created_list was planned as R16 but never merged, Q29); import twins "Created Influencer List", "Added Influencer to List"

Geo Analysis

Geographic audience analysis.
  • Code: geo/geo.controller.ts
  • Events: created_geo_analysis, regenerated_geo_analysis

PR / Journalist Outreach

Journalist search, media lists, AI pitch generation and sending.
  • Code: entity/controllers/*
  • Events: pr_journalist_search, pr_created_media_list, pr_generated_pitch, pr_sent_pitch (last one never reaches Mixpanel, Q26)

Social Listening

Segment-based listening: mentions, trends, insights. Own backend service.
  • Code: backend/social-listening + social-listening.controller.ts (main)
  • Events: social_listening_segment_created, social_listening_report_ready, created_social_listening_report, generated_social_trends_insight — entire family missing from Mixpanel (Q26)
  • Metering: package type 4

Brand Safety

AI analysis of influencer content risk. Own service.
  • Code: backend/brand-safety; callback to main on completion
  • No behavioral events; AI cost → ai_usage table

Monetization & account features

Trials & subscriptions

7-day card-first trial with anti-abuse gate; day-7 autocharge; Stripe + Cardcom (IL, ×1.17 VAT); plan upgrades.
  • Code: payments/payments.service.ts (gate :1545, trial :1634, conversion :500/:1710/:2210, upgrades :1349/:1410, idempotency guard :2084)
  • Cancel flows in users.service.ts (ternary :2195) + AI-agent retention call variant

Trial gating & friction UX

Daily/total quotas per feature, gated features, upgrade CTAs at 15 placements, unlock modal, book-a-call, sample reports.
  • Code: trial-gating.service.ts (client) + quota enforcement (server)
  • Events: the trial_* families (born 2026-06-30)

Teams

Multi-seat accounts; members get their own user_id under a main_user_id.
  • Events: team_member_added; import twin "Invited Team Member"
  • Analysis rule: always roll up to main_user_id

API access & credits

Programmatic API metered by the proxy (x-tokens-cost per route, package types, balance decrement per key).
  • Events: api_credits_added, api_credits_renewed (emitter unconfirmed)

White-label / resellers

~50 tenant domains run the platform under their own brand.
  • Server events route to per-label webhook URLs but tenant identity is STRIPPED from payloads → reseller traffic is invisible downstream (Q13)
  • All tenant domains load IMAI's client tags (Q12); VWO is imai-only; reseller linkage only via reseller_stripe_cuid

Onboarding

KYC-style onboarding with team invite step — bypassed for all IMAI signups since 2026-07-21 (straight to /trial). Forced-onboarding booking flows exist per CS rep.
  • Events: finished_onboarding (collapsing post-change), scheduled_forced_onboarding_*

Customer-facing tracking product

Conversion Pixel (customer SDK)

IMAI's customers install this on THEIR stores to attribute influencer-driven sales to campaigns. Not product analytics.
  • Components: sdk/pixel.js (served from cdn.influencermarketing.ai), Shopify web-pixel extension, WooCommerce plugin; Magento/BigCommerce auto-detect
  • Flow: ?imai_click_id/?imai_sc → cookie _imai_clickid (30d) → POST /tracking/ping·sdk-click·conversion → attribution clickId→coupon→IP(24h) → campaign conversion tables
  • Per-campaign toggle (pixelActive); domain allowlist (client_domains)
  • Legacy parallel path: Bubble wf/order-conversion-* still in the tutorial (Q21); client-side IP via ipify (removal blocked on Q23)

Internal analytics catalog (usage-ai)

In-repo analytics knowledge: SCHEMA.md (verified metric recipes) + usage-board with the customer health score (usage-board.service.ts:1909) replicating the Mixpanel formula. CS uses it for at-risk-renewal triage.
